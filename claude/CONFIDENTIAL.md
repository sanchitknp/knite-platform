# Confidential reference — not in this repo

Account identifiers, FNSKUs, shipment records, commercial performance and review
provenance are held **outside version control**.

Ask the account owner for `KNITE_CONFIDENTIAL.md`.

What lives there and not here:

- GSTIN, LLPIN, PAN, dispatch address, support number
- Amazon ads entity ID and Brand Store subEntity ID
- FNSKUs per SKU
- FBA shipment IDs, fulfilment centre address, e-way bill, challan, transporter, vehicle
- Advertising performance and Brand Analytics impression share
- Review counts and provenance notes
- knite.in content discrepancies

Placeholders in these docs (`<FNSKU>`, `<shipment id>`, `<GSTIN — see confidential
reference>`) point at that file.
