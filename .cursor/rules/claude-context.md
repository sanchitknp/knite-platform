# Claude Desktop Context

This project has prior conversation history from Claude Desktop/Code stored
in `docs/claude-context/`. When working on tasks that relate to past
decisions, architecture discussions, or debugging sessions, reference
those files for additional context.

## How to use

- Browse `docs/claude-context/` for summaries of past development sessions.
- Use `@docs/claude-context/<filename>.md` in Cursor chat to pull in
  a specific conversation as context.

## Available context files

- `meta-webhook-ngrok-setup.md` — Full build history of the Knite Platform:
  ngrok/Meta webhook setup, WhatsApp bot flows (technician onboarding,
  installation, referrals), WhatsApp Flows integration, media handling,
  job lifecycle, and key architecture decisions.
